Procure TO Pay Flow 

1. Requisition
T-code: ME51N   
Main Table: EBAN, EBKN  
 User: Requester / Department EmployeeAI 
 Agent Job: Read unstructured purchase requests from emails or chat messages (e.g., "We need 50 safety helmets") and automatically draft or create the Purchase Requisition via API/BAPI.
2. Purchase Order
T-code: ME21N  
 Main Table: EKKO, EKPO  
  User: Purchasing Agent / BuyerAI
Agent Job: Automatically convert approved requisitions into Purchase Orders, select the optimal vendor based on historical pricing/delivery terms, and send the PO via email.
3. Goods Receipt
T-code: MIGO   
Main Table: MKPF, MSEG, MATDOC
User: Warehouse Clerk / Inventory Manager
AI Agent Job: Process incoming delivery notes or packing slips using OCR (Optical Character Recognition) and auto-post the Goods Receipt confirmation against the corresponding PO.
4. Invoice
T-code: MIRO   
Main Table: RBKP, RSEG, RBMA   
User: Accounts Payable Accountant
AI Agent Job: Perform 3-way matching automatically (comparing PO, Goods Receipt, and Vendor Invoice quantities/prices) and flag discrepancies or pre-approve matching invoices for posting.
5. Payment
T-code: F110   
Main Table: BKPF, BSEG 
 User: Finance / Treasury Manager
 AI Agent Job: Analyze cash flow constraints, suggest optimal payment runs for due invoices, and execute automated payment proposals through the automatic payment program.
